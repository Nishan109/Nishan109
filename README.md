## ⚡ Professional Profile & Core Focus

> 👋 **Hello! I'm Nishan Singh.** I am a **Cloud Engineer & Infrastructure Solutions Architect** specializing in production-grade cloud deployments on **Amazon Web Services (AWS)**.

- 🔒 **Security & Networking:** VPC Design, Multi-AZ Subnet Isolation, Security Group Chaining, Dual Application Load Balancers (ALBs), Nginx Reverse Proxying.
- 🛠️ **Infrastructure as Code:** Modular Terraform automation, CloudFormation templates, and repeatable deployment pipelines.
- 🐳 **Containerization:** Kubernetes (AWS EKS), Amazon ECS Fargate serverless containers, and Docker.
- 🗄️ **Databases & Runtimes:** Amazon RDS (MySQL 8.4) with KMS Encryption, Node.js REST APIs, PM2 process management, and React SPAs.
